Component Vault

再利用可能なHTMLコンポーネントを作成・プレビュー・整理・エクスポートするための、ローカルファーストなWindowsデスクトップワークスペース。

Windows版インストーラーをダウンロード

Windows 10/11（64ビット） · バージョン 1.0.8 · ポータブル版 ZIP

設定から、アプリの表示言語を日本語と英語で切り替えられます。選択した言語は次回起動後も保持されます。

NSIS インストーラー版は、設定の「アプリの更新」から更新を確認し、ダウンロード後に再起動してインストールできます。更新の確認・ダウンロードは自動では行われません。

概要

Component Vault は、HTML、CSS、JavaScript のコンポーネントをひとつのワークスペースで管理します。リッチなコードエディターで編集し、安全なリアルタイムプレビューで確認できます。Workbench、Gallery、Adaptive Studio の表示を目的に応じて切り替えられます。すべてのライブプレビューはライト／ダーク背景をその場で切り替えられ、選択は次回起動後も保持されます。

Codex を含むローカルエージェントは、内蔵の安全な CLI から同じライブラリを操作できます。GUI が開いている場合も、アプリの検証・競合検出・更新通知を共有するため、SQLite ファイルを直接編集せずに安全に連携できます。

主な機能

  • HTML・CSS・JavaScript タブと、ライト／ダーク背景を切り替えられるサンドボックス化されたライブプレビュー
  • コンポーネントライブラリを閲覧しやすい Gallery と Studio レイアウト
  • インポート、エクスポート、元に戻す、復元、コマンドパレットのワークフロー
  • ライブラリとコンポーネントの右クリック操作（開く・名前変更・複製・削除）と、Undo による削除の取り消し
  • Codex などのエージェントが Agent Guide を通じて利用できる、安全なローカル CLI と競合検出
  • オフラインファーストの保存と、Windows向けネイティブパッケージ
