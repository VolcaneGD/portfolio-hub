Component Vault

A local-first Windows desktop workspace for creating, previewing, organizing, and exporting reusable HTML components.

Download installer for Windows

Windows 10/11 (64-bit) · Version 1.0.0 · Portable ZIP

Overview

Component Vault keeps HTML, CSS, and JavaScript components in one focused workspace. Edit in a rich code editor, preview safely in real time, and switch between Workbench, Gallery, and Adaptive Studio layouts.

Highlights

  • HTML, CSS, and JavaScript tabs with live sandboxed preview
  • Gallery and studio layouts for browsing component libraries
  • Import, export, undo, recovery, and Command Palette workflows
  • Offline-first storage with Windows-native packaging
