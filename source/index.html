Component Vault 1.0.3 を公開しました。Codex などのエージェント向けに、安全なローカル CLI、競合防止用リビジョン、操作を自己説明する Agent Guide を追加しました。

Component Vault 1.0.1 を公開しました。保存済みHTMLコンポーネントを表す新しいアプリアイコン、カード画像の表示修正、Windows配布物へのISCライセンス同梱を含みます。
