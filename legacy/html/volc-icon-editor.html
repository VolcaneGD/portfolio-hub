Volc Icon Editor

高品質なアイコン作成・画像加工デスクトップツール。AI背景透過機能を標準搭載。

⬇ Download for Windows

※初回実行時、AIモデル（約170MB）の自動ダウンロードが行われます。

Overview

「VOLC Icon Editor」は、AI生成画像などをデスクトップアイコン（.ico）やWeb用素材（.png）に加工するためのツールです。背景透過、テキスト合成、位置調整を直感的なUIで行えます。

主な機能

  • AI背景透過: rembg (U-2-Net) を使用した高精度な背景除去機能を搭載。
  • テキスト合成: フォント、色、サイズ、太字、位置を細かく設定。自由な配置が可能です。
  • カスタムフォント登録: 反映されないフォントファイルを直接指定して読み込む「自己解決機能」を搭載。
  • 高度なプレビュー: ズーム機能とドラッグ移動により、細部まで確認しながら編集可能です。
  • マルチエクスポート: Windowsアイコン形式(.ico)およびPNG形式に対応。

使い方

  1. 画像の読み込み: 加工したい画像を中央エリアにドラッグ＆ドロップするか、クリックしてファイルを選択します。
  2. 背景透過: 「背景を透過する」にチェックを入れると、AIが自動で背景を削除します。
  3. テキストの追加: 入力欄に文字を入力し、「⚙️ テキスト詳細設定...」から調整後、「変更を反映」をクリックしてください。
  4. 保存: 右パネルの「ICOとして保存」または「PNGとしてエクスポート」を選択します。

フォントが反映されない場合

インストール済みのフォントが反映されない場合は、詳細設定画面の「📁 フォントファイルを個別に登録...」から、直接フォントファイル（.ttf / .otf / .ttc）を選択してください。

動作環境

Windows 10 / 11 (64bit) 推奨。Python 3.12 / Pillow / rembg 環境で動作。
