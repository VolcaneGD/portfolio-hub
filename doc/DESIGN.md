# VOLCANE Project Design Specification

## 0. サイト分離ポリシー（最重要事項）
本プロジェクトは、趣旨の異なる2つのデザインシステムを完全に分離して共存させる。
- **VOLCANE (ポートフォリオ)**: 従来のダークモード、サイバー、プレミアムなデザインを**鋼の意志で完全に維持**する。ユーザーの許可なくここを変更することは許されない。
  - 対象: `html/index.html`、およびツール以外の紹介ページ。
  - 使用CSS: `styles/style.css`、`styles/app-details.css`。
- **VOLC TOOLS (ツールサイト)**: モダンで親しみやすく明るいデザインへ**刷新**する。独立した別サイトとして扱う。
  - 対象: `html/tools-index.html`、および `background-remover.html` 等のWebツール個別ページ。
  - 使用CSS: `styles/tools.css`、`styles/tool-details.css`。

## 1. ブランドアイデンティティ (VOLC TOOLS)
- **ブランドロゴ**: 「VOLC」の4文字を圧倒的なサイズで配置。
  - **タイポグラフィ**: `3.2rem` / `font-weight: 900` / `letter-spacing: -3px`。
  - **装飾**: 白の2pxシャドウと、薄い黒の5pxシャドウを重ねた立体的なデザイン。
  - **シンボルカラー**: 「V」のみを `#ff3b3b` (VOLCANE Red) とし、ドロップシャドウで発光感を演出。
- **サブテキスト**: 「ヴォルク ツールズ」。
  - **タイポグラフィ**: `0.75rem` / `font-weight: 800` / `letter-spacing: 0.4em`。
  - **カラー**: `#94a3b8` (Slate Gray)。

## 2. デザインコンセプト
- **親しみやすさと直感性**: Webツール専用サイト「VOLC TOOLS」として、明るくモダンで直感的なUIを提供。
- **クリーン & ソフト**: 大きな角丸、十分な余白、柔らかい影（Soft Shadows）を用いた清潔感のある構成。
- **コンテンツ重視**: AdSense審査を意識し、ツール操作エリアの下部に1,000文字程度の技術解説やFAQを備えた「読み応えのある記事セクション」を必須とする。

## 3. レイアウト構造
### 2カラム・サイドバー構成
- **左サイドバー (Sidebar)**: 固定幅（280px〜300px）。プロダクト一覧をカテゴリ別に表示。
  - **上部パディング**: ロゴを際立たせるため `40px 24px 32px` の広い余白を確保。
  - ブランドロゴ
  - **論理的カテゴリ分類**:
    - **AI Magic**: ニューラルネットワーク（Transformers.js/Tesseract.js等）を使用した推論ツール。
    - **File Converters**: フォーマット変換ツール。
    - **Design & Utilities**: 数学的な計算・抽出アルゴリズムを用いた便利ツール。
  - ユーティリティ：About / Privacy Policy
  - **[追加機能]**: サイドバー下部に「GitHub」や「お問合せ」へ誘導する大きな Pill ボタン。
- **メインコンテンツ (Main Content)**: フレキシブル。サイドバーで選択された内容や各ツールの詳細を表示。
  - ヘッダー：現在選択中のカテゴリ名を表示するパンくずリスト。
  - ボディ：プロダクトグリッド。

### 2.1 Z-index 管理
- Sidebar: 1000 (常に最前面)
- Mobile Header: 1100

## 3. カラーパレット
- **メインカラー**: `#00C4CC` (Canva Teal - 信頼と活気)
- **アクセントカラー**: `#7D2AE8` (Canva Purple - クリエイティビティ)
- **背景色**: `#F4F7F6` (ごくわずかに緑がかった明るいグレー)
- **サーフェス（カード等）**: `#FFFFFF` (純白)
- **テキスト**: `#0E1217` (深みのあるチャコールグレー。純粋な黒を避ける)
- **ホバー色**: `#F0F2F5` (サイドバー項目用)
- **境界線**: `#E1E4E8` (非常に薄いグレー)

## 5. タイポグラフィ
- **フォントスタック**: 
  - `Inter` (英語/数字)
  - `Noto Sans JP` (日本語)
- **スタイル**:
  - 見出しは太めのウェイト (`font-weight: 700`)。
  - 本文は読みやすさを重視し、行間を広め (`line-height: 1.6`) に設定。
  - プロダクト名は `0.95rem`〜`1rem` 程度に抑え、サイドバーの密度を適度に保つ。アクティブな項目は `var(--color-primary)` で強調。

## 6. コンポーネント定義
### サイドバー項目
- ホバー時に背景が薄いグレー (`#F0F2F5`) になり、テキストがメインカラーに変化。
- **カテゴリ見出し (.nav-label)**: メインカラー (`#00C4CC`)、`0.72rem`、太字、全大文字 (`text-transform: uppercase`)。リンク項目と差別化し、`cursor: default` で非クリック対象であることを明示。
- カテゴリごとにアイコン（Lucide系）を配置し、視覚的な識別性を向上。
  - Android Apps: スマホ型アイコン
  - Web Tools: 魔法の杖、またはパレット
  - Extensions: パズルピース

### プロダクトカード
- `border-radius: 16px` (非常に大きな角丸を採用し、親しみやすさを演出)。
- `box-shadow`: `0 2px 12px rgba(0,0,0,0.04)`。
- ホバー時に `transform: translateY(-5px)` と `box-shadow` の強調。
- プロダクトのサムネイル画像はアスペクト比 16:9 または 4:3 で統一。

#### アクションボタン
- **実行ボタン (.btn-execute)**: 50pxの完全な角丸 (Pill)。TealからPurpleへのグラデーション背景。
- **回遊ボタン (.view-all-link)**: アウトライン形式 (`2px solid var(--color-primary)`)。
  - **インタラクション**: ホバー時に背景を塗りつぶし、`translateY(-3px)` のリフトアップと強力なシャドウを適用。
  - **構成**: テキストと SVG 矢印アイコンを組み合わせたモダンなボタン。

#### ツール詳細ページ (Tool Details)
  - サイドバーはポータルと共通。
  - メインエリア上部にパンくずリスト (`Home / Web Tools / Current Tool`)。
  - **アイキャッチ**: ツールアイコンを **240px x 240px** の巨大サイズで中央配置。角丸は **48px**。
  - **ワークスペース (Workspace)**: 操作の主役となる白いボックス（`workspace-surface`）。
  - **記事セクション**: 技術解説、FAQ、更新履歴（Changelog）を含む。

## 7. マイクロインタラクション
- サイドバーのクリック時に、現在地を示すインジケーター（左側のバー）を表示。
- ページの遷移はフェードインで滑らかに表現。

## 8. モバイル対応 (Responsive)
- モバイル環境ではサイドバーを非表示にし、左上のハンバーガーメニューからドロワーとして表示。
- メインコンテンツは1カラムにスタック。
