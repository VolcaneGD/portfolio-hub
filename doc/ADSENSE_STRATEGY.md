# 🎯 AdSense審査通過に向けた戦略指南書：VOLCANE Portfolio Hub 再定義

## 1. 現状の課題：「有用性の低いコンテンツ」とは何か
Google AdSenseの審査で「有用性の低いコンテンツ」と判定されるのは、多くの場合以下の理由によります。
- **機能（ツール）のみで「文章（テキストデータ）」が不足している。**
- **ネット上に溢れている汎用的なツール（文字数カウントなど）と同じで、サイト独自の付加価値が見えない。**
- **ユーザーが「読む」ための情報（開発の背景や技術的解説）が欠けている。**
- **見本とするサイト**: https://amix-design.com/tools

本指南書では、これらの課題を解決し、サイトを「高品質な技術メディア兼ポートフォリオ」へと昇格させる手順を定義します。

---

## 2. 戦略の3本柱

### ① 「独自コンテンツ（記事セクション）」の追加
ツールとは別に、開発プロセスや技術的課題を深掘りした「記事」を追加します。
- **目標**: 最低3〜5本の技術記事（各1,000文字以上）。
- **テーマ案**:
    - 「WebAssemblyとTransformers.jsを用いた、サーバーレス背景透過の実現」
    - 「個人開発におけるAdSense審査の壁と、それを乗り越えるためのUI/UX戦略」
    - 「React/TypeScriptを用いないバニラJSによる軽量Webツールの設計思想」

### ② 個別ツールページの「情報量」を3倍にする
現在のタイトル・概要・ボタンだけの構成から、以下のセクションを追加した構成へ変更します。
- **開発の背景 (Background)**: なぜこのツールが必要だったのか。
- **主な機能とこだわり (Features)**: 他の類似ツールと何が違うのか。
- **技術仕様 (Technical Specs)**: どのような技術（ライブラリ、アルゴリズム）を使用しているか。
- **よくある質問 (FAQ)**: ユーザーが疑問に思う点への回答。
- **更新履歴 (Changelog)**: 継続的にメンテナンスされている証拠。

### ③ E-E-A-T（専門性・経験・権威性・信頼性）の確立
「誰が運営しているか」を明確にし、サイトの信頼性を担保します。
- **ABOUTページの独立**: 開発者としての活動実績、スキルセット、Mission（ビジョン）を詳しく記載。
- **コンタクトフォームの整備**: 単なるメールリンクではなく、信頼感のあるフォーム形式への検討。

## 3. 具体的な実施ステップ

### ステップ1：ブログ（Articles）基盤の構築
- [ ] `articles/` ディレクトリを作成。
- [ ] 標準的な記事レイアウト用CSSの作成。
- [ ] `index.html` に最新記事セクションを追加。

### ステップ2：コア・アーカイブの作成（3大注目ツール）
特に独自性が高い以下の3つのツールを「看板コンテンツ」として強化します。
1. **背景透過AI**: 技術解説を1,500文字追加。
2. **Inner Compass (MBTI診断)**: 診断アルゴリズムの解説を追加。
3. **スタークロニクル**: 世界観とゲームバランスの設計思想を追加。

### ステップ3：汎用ツールの「スクラップ・アンド・ビルド」
- [ ] パスワード生成器や文字数計算など、競合が多いツールについては、逆に「いかに軽量か」「いかにプライバシーに配慮しているか（サーバーへ送っていない）」を強調するテキストを1,000文字程度書き下ろす。
- [ ] もし文章が書けない場合は、審査期間中のみ非表示にする（コンテンツの希薄化を防ぐ）。
